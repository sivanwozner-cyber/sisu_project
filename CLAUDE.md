# CLAUDE.md

## Project
A personal task-management system, with WhatsApp reminders planned for a later
phase (via Green API). Currently only the project skeleton is being set up.

## Tech Stack
- **Next.js 14** (App Router)
- **Prisma** (ORM)
- **SQLite** (database)
- **Tailwind CSS** (styling)
- **shadcn/ui** (UI components)

## `.claude/` directory
Project-tailored Claude Code customizations live here:
- `agents/` — custom subagents for this project
- `skills/` — custom skills
- `commands/` — custom slash commands

(These are empty for now and will be filled in as the project grows.)
