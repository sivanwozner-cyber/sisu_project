# Untitled — פרומפט ייסוד הפרויקט

## מה הקובץ עושה

ה-prompt המקורי שהמשתמש כתב כדי להגדיר את הפרויקט ולתת הוראות ראשוניות לקלוד. מתאר את הפרויקט ומבקש ליצור מבנה תיקיות ראשוני.

## תוכן עיקרי

- הגדרת הפרויקט: מערכת ניהול משימות אישית עם Next.js, Prisma, SQLite, Tailwind, shadcn/ui
- תוכנית עתידית: חיבור ל-Green API לתזכורות WhatsApp
- בקשות ספציפיות:
  - יצירת `.claude/agents/`, `.claude/skills/`, `.claude/commands/`
  - עדכון `CLAUDE.md`
  - **לא** להריץ `create-next-app` ולא להתקין dependencies

## למי הוא משויך

- **בעלות:** המשתמש (sivanwozner-cyber)
- **מטרה:** מסמך ייסוד — snapshot של הכוונה המקורית

## מיקום בפרויקט

`/Untitled` — שורש הפרויקט (ללא סיומת, נכתב ישירות)

## הערה

הקובץ לא מיועד להיות חלק מהפרויקט הסופי — זה draft פנימי של המשתמש. ניתן להסירו או לשנות שמו ל-`BRIEF.md` בהמשך.
